#  Estructuras de Datos – Trabajo Final

> 🎓 Proyecto final de la materia **Estructuras de Datos**: simulador de encuentros de fútbol entre países, aplicando árboles, hash tables, pilas y colas.


---

##  Objetivo

Modelar un sistema donde **países representan equipos de fútbol** que disputan encuentros, aplicando estructuras de datos para:
-  Organizar países en un **árbol binario de búsqueda** (orden lexicográfico)
-  Gestionar encuentros con **colas y pilas**
-  Búsquedas eficientes con **tablas hash**
- Procesar resultados y estadísticas

---

## Estructuras implementadas

| Estructura | Uso en el proyecto |
|------------|-------------------|
| Árbol Binario | Almacenar países ordenados para búsquedas rápidas |
|  Tabla Hash | Acceso O(1) a países por nombre/código |
|  Cola | Gestionar encuentros pendientes de procesamiento |
|  Pila | Historial de acciones / deshacer operaciones |
